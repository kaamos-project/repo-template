# Decisions

Lightweight ADRs: one section per decision. When a decision changes, update its entry and say why.

Use this shape:

```markdown
## Short name of the decision

**Decision**: what we chose.
**Why**: the reasons.
**Trade-off**: what it costs, and the alternatives we rejected.
```

## License: GPL-3.0

**Decision**: GPL-3.0, like the rest of Kaamos Project.
**Why**: the project and its forks stay free software.
